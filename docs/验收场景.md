# 验收场景

## 学校校历导入

- 从“新建校历”选择学年和学期，导入与自行制表并列显示
- 官网四个学年的八个学期均可导入，预填范围、教学周、考试、放假和调课
- 导入后依次走完现有步骤，沿用原值不增加撤销记录；需要更改的安排直接在对应步骤处理
- 多段跨月考试、跨年补课与月日格式年份保持正确
- 读取未完成时切换学期、返回当前校历或自行制表，晚到结果均不覆盖当前配置
- 同步失败时可重试或使用已保存校历，当前工作在作出选择前保留
- 新建同一学期也得到空表，撤销恢复旧配置及来源；重新打开保留来源说明
- 学校说明默认折叠，包含通知、原始附件、原文与待核对事项，图示在宽屏卡片内右侧、窄屏卡片下方常驻
- 静态部署读取定期同步目录，实时部署在选择导入或重新同步时抓取，离线使用内置目录

## 界面与交付

日历和步骤卡片居中，一次显示一个步骤。窄屏允许日历横向滚动，固定星期列保留，步骤与按钮可操作。检查日期标记、关联提示和粗边界无重叠截断。

日历卡片上下留白一致，宽屏图示在卡片内右侧竖排、窄屏在卡片下方横排，学校说明在下方折叠；展开后来源、待核对事项和日程分组，日期与正文对齐，内容可滚动。节日预设包含对应学期的中秋、国庆、元旦、清明、劳动、端午，自定义假期可继续添加。

七步导航常驻卡片顶部，点击可跨多步直达，当前步骤高亮。步骤条与“上一步”后退均保留假期和调课草稿；向前可回到编辑步骤，未处理假期时不能越过该步骤。未保存的新范围需用下一步应用，后退可取消。不可达步骤禁用，按钮状态与实际守卫一致；已有另一份草稿时可返回其编辑步骤。单端点取消时有提示，已保存数据与撤销历史保持。跳转到新建入口后可以返回原位置。

按 Escape 保留未保存的假期和调课内容，并提示使用保存、取消或清除按钮。菜单打开时只关闭菜单；范围、考试端点取消时有提示。范围条带保持完整，仅首尾按钮带有无障碍选中状态。

学校“国际劳动节”对应“劳动节”预设，编辑不产生重复记录且保留原名；撤销恢复原日期。1900 年 1—2 月的 Excel 数值日期与原配置一致，三张工作表采用同一转换。

步骤按钮支持 Enter 和空格，Tab 可遍历步骤条；新建入口先选择导入或自制。两套主题和窄屏下步骤条均可完整操作。选日提示与清除选择按钮位于当前步骤标题下，教学周未设置时整行空占位显示为空白。

不超过 600px 时，步骤条可横向滑动，一屏约三至四步，边缘淡出对应实际隐藏方向；按钮名称不挤压、页面无额外横向溢出。上一步、下一步与直接跳转时，当前步骤平滑进入视野，快速反向切换不闪跳；首尾完整可见。手动滑动后，同一步选日不拉回位置，Tab 可访问可用步骤。切回宽屏恢复完整七步，减少动态效果时直接定位，两套主题分别核对。

两主题分别检查 320、390、520px：顶部“文件”菜单与导出同排，菜单不越过屏幕边界，打开、保存、Escape、Tab 和外部点击均可用；宽屏直接显示“打开校历”和“保存校历”。保存的校历 JSON 包含配置、完整性状态和逐日数据；重新打开该文件、仅含配置的 JSON 或已有日历数据 JSON，恢复的日期与安排一致。底部上一步、下一步始终同排，完整下一步名称可通过读屏获取。图例清楚可读并居中换行，调课选零日、单日、双日以及切换对调／补课时，摘要和提交按钮保持稳定。

窄屏从七八月进入秋考试步骤，已有十一月日期平滑进入视野；冬考试、保留的假期与调课草稿同样可定位，固定星期列不遮住目标。新建、空配置、局部范围和跨年调课均使用当前有效范围；不写入参考日期。选日或同一步编辑保留手动滚动位置，快速切换与手动中止后无跳回；宽屏保持原有浏览位置。

方向键按网格移动，Tab 进入和离开日历，确认首个考试端点后焦点保持。悬停与键盘焦点显示直接关联日期，禁用日期无可点击反馈。

在教学周、考试和假期步骤点选日期时，日期属性栏不展开，日历卡片不因属性栏增高；完成制表后点击日期可以查看属性，继续编辑后属性栏隐藏。

上一步、下一步及完成预览协调页面高度和滚动；减少动态效果时保留完整功能。两套主题分别核对最终状态与继续编辑。

范围缩小后进入第三步、返回第二步展开空表、跨步骤跳转及进入更宽的调课范围时，日期表有连续交接，文字不缩放；过渡结束或中断后，旧表快照和临时样式完全清理。快速前后切换、滚动中断和窗口调整后仍可选日。

冬／夏考试中，教学周内和更早日期不可点击，键盘入口落在合法日期；选择首端点后，非法日期不能覆盖端点或产生配置修改。同日两个合法端点仍可保存单日考试。秋／春第八周的考试继续可选。

假期选日从零到一、多日增减、全部取消时，日历和步骤卡片高度保持一致；未设置显示“暂时跳过”，已保存且未修改显示“下个节日”，修改中显示“取消编辑”，三者共用同一位置，其余按钮的位置保持稳定。反复向后切换到最后一项后按钮禁用，保存末项也不循环回前面的节日；点击节日名称可回到任意一项。日期明细主动展开后按内容占用空间。

课程对调与补课在未选日、一个日期、两个日期、清除选择及方式切换之间，关系摘要始终位于步骤卡片，日历与步骤卡片高度保持稳定。宽屏和窄屏均核对这些状态。

正常反馈和错误提示均显示在右上方，不覆盖底部按钮且不拦截点击。图例色块在两套主题背景上清晰可辨。存在实体横向滚动条时，日期表上下留白仍保持均衡。

宽度充足时，日期表与整张卡片中心对齐且没有横向溢出；慢慢收窄窗口时，侧边留白连续减少，日期表平滑回到内容区居中。切换更长的日期范围后自动重新计算，居中留白不增加横向溢出。

两个主题的同类按钮尺寸一致，“更多”与相邻按钮对齐。假期、调课草稿可保存时突出保存；保存或取消后，下一步或完成按钮恢复实心。标签、记录操作、步骤导航保持各自点击尺寸，窄屏按钮不被截断。

新建假期未选日期或缺少名称时保存禁用；清空已有记录的全部日期后显示警示色“清除日期”，点击后清除原日期、预设节日保留，撤销可恢复原安排。假期未保存时，“下一步”和步骤条对应入口均禁用并提供相同原因；完整范围的下一步仍可应用范围。调课零日、单日或执行日冲突时保存禁用，合法两日和编辑原记录可保存；完成按钮检查全部保留草稿。

禁用原因出现在按钮可访问名中；名称缺失和调课冲突在当前步骤可见。用键盘跳过至末项、取消编辑、保存、清除和移除最后一个日期后，焦点保持在有效控件或当前步骤标题，按 Tab 从当前卡片继续。

构建产物的首页链接和图片均为本地相对路径，制表页脚本和样式内联。完整项目移入独立目录后仍能测试与构建。
