# 验收场景

## 学校校历导入

- 官网四个学年的八个学期均可选择，制表范围覆盖各自日期网格全部日期
- 不连续、跨月考试与跨年补课保持原意，月日格式使用当前学年
- 逐条取消放假或调课后仅导入勾选项，切换学年和学期保留勾选结果
- 导入是一个可撤销动作，失败、关闭或超时保留当前校历
- 静态部署读取定期同步的目录，实时部署在打开面板或刷新时请求学校同步
- 来源失败、附件破损、版式不符时保留已有有效版本并显示同步提示
- 离线单页可使用内置目录，学校通知和原始附件链接可供溯源
- 两个主题均可导入后继续编辑、保存配置、导出 Excel

## 日期与排版

| 输入／操作 | 预期结果 |
| --- | --- |
| 2023—2024 秋冬 | 空表为 2023-07-01 至 2024-02-29 |
| 2023—2024 春夏 | 空表为 2024-01-01 至 2024-08-31 |
| 2000—2040 各学年两组日历 | 日期连续、无重复、闰日正确，格子与自然星期一致 |
| 2023-09-18 为第一周周一 | 11 月 12 日秋八周，11 月 13 日冬一周，1 月 7 日冬八周 |
| 秋考试为 11 月 11 日、18 日 | 两天分别保留秋八周、冬一周 |
| 冬考试为 2024-01-09 至 18 日 | 十个考试日；1 月 19 日开始寒假 |
| 冬考试从 2024-01-08 开始 | 允许，恰为十六周后的第一天 |
| 7 月 1、2 日位于首列周末 | 月份表头从 7 月 3 日所在列开始，粗边界衔接 |
| 范围从周中开始，或仅包含周末 | 缺少日期的格子留空，表头和导出有效 |
| 缩小输出范围再恢复 | 原教学周和安排保持 |

## 提交、草稿与恢复

| 输入／操作 | 预期结果 |
| --- | --- |
| 范围先点末日再点首日 | 自动排序，条带连接，区间外继续显示 |
| 范围点击下一步 | 正式应用范围，取消条带并裁剪 |
| 只有范围首个端点 | 阻止下一步；清除后可继续 |
| 第一周选择非周一 | 日期不可选择 |
| 改动起点与已有考试冲突 | 拒绝提交，配置与编辑状态保留 |
| 冬考试同日点两次 | 保存单日考试区间 |
| 放假选择不连续两日 | 间隔日期不补选，保存后生效 |
| 放假草稿尚未保存时导出 | 文件仅包含已应用配置 |
| 自定义放假保存 | 清空编辑器，准备下一条 |
| 合并节日对应多个预设 | 编辑共用的同一条记录 |
| 切换调课方式 | 两个日期继续保留 |
| 调课两个位置已有日期，再点第三日 | 提示先取消一个位置 |
| 调课草稿未处理就完成制表 | 提示先保存、清除或取消编辑 |
| 未完整校历完成／导出 | 允许，导出含缺项说明 |
| 导入成功／失败 | 成功完整替换，失败保留全部状态 |
| 撤销 | 恢复配置，最多回退最近三十次配置变更 |
| 重新打开 | 恢复匹配配置的步骤、密度和完成预览 |

## 调课与导出

| 输入／操作 | 预期结果 |
| --- | --- |
| A 与 B 对调 | 各引用对方原安排 |
| A 补 B | 仅 A 的执行安排改变 |
| A 补 B，B 补 C | A 仍引用 B 的原安排 |
| 多日补同一原课程日 | 允许共享引用目标 |
| 重复占用执行日 | 报冲突，保留当前配置 |
| 同日考试、放假和调课 | 信息同时保留，自然星期和周次不变 |
| 跨年且引用范围外日期 | 引用完整保留 |
| JSON 往返 | 配置可继续编辑，派生结果一致 |
| Excel | 三张表，日期为数值，月份粗线完整，名称正确转义 |
| 暖纸／清透导出同一配置 | 文件使用相同业务数据 |

## 界面与交付

日历和步骤卡片居中，一次显示一个步骤。窄屏允许日历横向滚动，固定星期列保留，步骤与按钮可操作。检查日期标记、关联提示和粗边界无重叠截断。

方向键按网格移动，Tab 进入和离开日历，确认首个考试端点后焦点保持。悬停与键盘焦点显示直接关联日期，禁用日期无可点击反馈。

上一步、下一步及完成预览协调页面高度和滚动；减少动态效果时保留完整功能。两套主题分别核对最终状态与继续编辑。

构建产物的首页链接和图片均为本地相对路径，制表页脚本和样式内联。完整项目移入独立目录后仍能测试与构建。
