# 交互逻辑

## 1. 页面与流程

首页提供暖纸、清透两种风格。制表页面上方居中显示日历，下方居中显示较窄的设置卡片。卡片每次展示一个步骤，通过上一步、下一步切换。进入选日步骤后可直接点击日历。

| 步骤 | 输入 | 提交时机 |
| --- | --- | --- |
| 学年与学期 | 起始年、秋冬／春夏 | 下一步 |
| 制表范围 | 日历中的两个端点 | 下一步 |
| 第一教学周 | 一个周一 | 点击后即时提交 |
| 秋／春考试 | 逐日添加或取消 | 每次点击即时提交 |
| 冬／夏考试 | 两个端点 | 第二个端点选定后提交 |
| 放假日期 | 名称、逐日集合 | 保存 |
| 课程对调与补课 | 方式、两个日期 | 添加／保存调课 |

所有提交先校验整份配置。校验失败时保留已应用配置及编辑内容，显示具体原因。

## 2. 七步操作

### 学年与学期

输入变化先保存在当前编辑状态中。点击下一步时，相同学年和学期组继续使用已有配置；改变其中任意一项则创建对应空白配置，考试、放假和调课从空集合开始。新建配置可以撤销。

### 制表范围

进入本步展示已经扩展好的完整空表，暂时隐藏安排标记。原配置中的安排仍保留。

先后点击两个日期，自动按时间排序，用条带连接整个待应用区间。区间外日期继续显示。再次点击日期会开始一轮新的选择。“使用整个空白日历”将完整空表设为待应用区间。

点击下一步后应用范围，裁剪区间外日期、取消条带，恢复安排标记。只选一个端点时需补齐或清除才能前进。没有新选择时继续使用当前范围。清除选择或返回上一步会取消本轮端点。

### 第一教学周

只有周一可以选中。点击后立即生成连续的 8 + 8 周。已有考试与新起点冲突时，提示原因并保留原配置。

### 秋／春考试

逐日点击加入，再次点击取消。已选日期列表同步更新，也可以从列表删除单日。日期之间保持独立。

### 冬／夏考试

第一次点击形成锚点，第二次点击自动排序并保存整个区间。同一天点击两次可以设置单日考试。选择过程中原考试区间继续保留，直到新设置通过校验。

“清除本次选择”取消临时锚点；“清除考试日期”删除已保存区间。切换步骤会取消未完成的锚点。点选首个端点后保持日期焦点，方便继续用键盘选日。

### 放假日期

初次进入或重置编辑器时选中首个未设置节日，全部已设置时选中第一个节日。点击节日名称后即可在日历逐日选择。数量始终可见，具体日期列表默认折叠。

保存时提交当前名称和日期。预设节日保存后切换到下一个未设置节日；全部完成时停留在当前预设。自定义放假保存后清空编辑器，准备填写下一条。

“暂时跳过”切换到其他预设，当前草稿不提交。“其他放假”显示自定义名称输入。切换预设会载入相应已保存记录，并放弃离开项的未保存选择。

已保存安排列表默认折叠，展开后可以编辑或删除。编辑回填名称和日期；清空已有记录全部日期后保存即删除该记录。取消编辑保留已保存内容。合并节日的编辑提示说明哪些名称共用这条记录。

### 课程对调与补课

“课程对调”和“补课”并排显示，点击切换。切换方式保留两个日期，并按新方式解释 A、B。

本步临时展示完整空白日历，便于选择正式范围外日期，正式范围保持不变。先点 A，再点 B；日历显示角色、关联日期和未保存提示。再次点击已选日期清空该位置，随后可重新选择。两个位置均有日期时，点击第三日会提示先清除一个位置。

保存通过后直接生效，清空选日草稿，保留当前方式。编辑已有记录时回填方式和日期；取消编辑保留原记录；清除选择仅清除编辑器中的日期。删除可通过撤销恢复。

编辑导入记录时，如果将两个日期纳入展示后仍不超过 367 天，会扩大临时日历；超出时保留空白日历范围，已回填的引用日期仍保留在记录中。

## 3. 完成预览

“完成制表”收起步骤卡片和选日提示，按正式范围展示日历。点击日期查看详情，“继续编辑”回到第七步。

调课有未保存日期或正在编辑的记录时，先保存、清除选择或取消编辑，再完成制表。配置未完整也可以进入完成预览，导出时单独标明缺项。

## 4. 配置、草稿与视图

| 状态 | 内容 | 保存范围 |
| --- | --- | --- |
| 已应用配置 | 学年、范围、起点、考试、放假、调课 | 自动保存、配置文件与导出 |
| 编辑草稿 | 尚未确认的范围、放假日期、调课两日 | 当前打开期间的内存 |
| 视图偏好 | 步骤、密度、完成预览 | 独立的本地偏好 |

预览可以包含编辑草稿，文件导出始终使用已应用配置。

| 操作 | 草稿处理 |
| --- | --- |
| 范围下一步 | 完整区间提交；单端点阻止前进 |
| 范围上一步／清除 | 取消本轮范围 |
| 冬／夏考试切换步骤 | 清除临时端点，保留已保存区间 |
| 放假／调课切换步骤 | 草稿留在当前会话内存中 |
| 放假切换预设、跳过、取消 | 载入对应记录，离开项草稿不提交 |
| 导入、撤销、重新打开 | 重置编辑器与临时端点 |

放假草稿通过保存进入配置，最终完成操作只检查调课编辑状态。

每次配置提交将修改前的配置放入撤销历史，最多保留最近 30 次，包含新建和导入。撤销恢复配置并重置草稿，视图继续保持当前步骤；撤销范围为已提交的配置变更。当前流程提供撤销操作。

## 5. 自动保存与导入

自动保存成功后，重新打开可恢复配置，以及与该配置匹配的步骤、密度和完成预览。配置不匹配时，步骤与完成状态从初始值开始，合法的密度偏好仍可使用。

草稿、当前节日选择、当前调课方式、焦点、滚动位置和撤销历史在每次打开时重新初始化。存储失败会提示保存配置文件，已在内存中应用的修改仍可继续使用。

导入支持配置 JSON 和包含配置的日历数据 JSON。成功后完整替换当前配置、重置草稿、退出完成预览并保留步骤；失败时保留当前内容。导入入口接受最大 2 MiB 的 JSON 文件。

同一存储来源下，两套主题共用配置与视图偏好。离线文件的存储隔离取决于运行环境，可用配置文件转移数据。已打开的多个页面各自维持当前会话，重新打开时读取保存内容。

## 6. 键盘、反馈与动画

日历只有一个 Tab 入口。上下方向键在同一周移动，左右方向键移动到相邻周的同一星期，跳过空格和不可选日期，边界保持在当前行列。Enter 或空格执行该日期操作，Tab 离开日历。

重绘后保持有效焦点，隐藏在横向区域外的日期会滚入可见区域，并避开固定星期列。Escape 优先关闭“更多”菜单；菜单关闭时，取消临时端点或重置当前编辑器。

有横向隐藏内容时显示对应边缘阴影。鼠标悬停或键盘聚焦调课日期时，同时描边其直接关联日期；关联提示仅影响呈现。日期标记和详情也提供完整关联信息，触屏操作可以直接使用。

步骤切换同时协调设置卡片高度、日历位置和页面滚动。数据在动作执行时更新；手动滚动、相关按键或视口变化可以中止过渡。开启减少动态效果时直接显示终态。两套主题采用相同布局和操作，主题参数控制外观及动画节奏。
