# 校历生成器

校历生成器用于制作采用 **8 + 8 教学周**的秋冬、春夏学期校历，整理教学周、考试、寒暑假、节假日和调课安排，并输出可编辑配置、逐日数据和 Excel 表格。

它可以独立制表，也可以为排班、课程规划和校园管理工具提供日历数据。计算规则与制表流程均为独立 JavaScript 模块，便于接入小程序或应用软件。

![暖纸与清透](web/assets/selector.jpg)

## 开始使用

打开 [风格选择页](https://guchl9.github.io/academic-calendar/)，选择 [暖纸](https://guchl9.github.io/academic-calendar/paper.html) 或 [清透](https://guchl9.github.io/academic-calendar/mist.html)。两套界面功能相同，各自的 HTML 文件包含完整脚本和样式，支持离线制表。

本地使用时，在项目根目录执行 `node scripts/build.js`，再打开生成的 `dist/index.html`。

按照下方卡片依次完成：

1. 选择学年和秋冬／春夏学期。
2. 在空白日历上选择制表首尾日期，点击下一步确认。
3. 选择第一教学周的周一，生成连续的 8 + 8 周。
4. 逐日选择秋／春学期考试日期。
5. 选择冬／夏学期考试首尾日期。
6. 按节日逐日选择并保存放假日期。
7. 添加课程对调或补课，完成制表。

日历中的自然星期、教学周、考试、放假和课程执行安排分别保存。同一天可以同时属于秋八周、秋学期考试日和放假日。

## 保存与导出

| 文件 | 用途 |
| --- | --- |
| 配置 JSON | 保存设置，重新打开后继续编辑 |
| 日历数据 JSON | 为其他程序提供配置、完整性状态和逐日数据 |
| Excel | 包含“校历”“逐日数据”“放假与调课”三张工作表，方便查看、打印和整理 |

导出读取已保存的配置。未完整的校历也可以导出，文件会标明缺少的设置。自动保存用于恢复当前设备上的工作，配置文件适合长期保留和转移。

节日预设提供名称，具体放假日期由使用者填写。适用规则为秋冬或春夏各八周；小学期、特殊考试和其他教学周长度属于独立的扩展范围。

## 本地开发

需要 Node.js 20 或更高版本，无第三方运行时依赖。在项目根目录执行：

```sh
node --test
node scripts/build.js
node scripts/serve.js
```

`node scripts/serve.js` 启动本机预览，地址为 `http://127.0.0.1:4175`。构建结果位于 `dist/`，首页为 `index.html`。将完整的 `dist/` 内容作为静态站点发布即可保留风格选择页和两套界面。

GitHub Pages 通过 [发布工作流](.github/workflows/pages.yml) 自动部署：更新 `main` 分支后，先运行测试，再构建并发布 `dist/`。

```text
src/core/           日期、规则、逐日计算与表格布局
src/application/    制表会话、草稿、导航、撤销与偏好
src/adapters/web/   页面呈现、输入、存储、文件与动画
src/export/         Excel、XML 与 ZIP 编码
web/               页面模板、主题样式与预览图片
examples/          可打开的秋冬、春夏配置样例
tests/             规则、交互、恢复、导出与构建测试
scripts/           构建与本机预览
docs/              使用规则与开发约定
dist/              可直接使用的静态成品
```
